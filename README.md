# Movie Recommendation System using Machine Learning

## Project Overview
This project is a content-based movie recommendation system built using Python and Machine Learning techniques. The system recommends similar movies based on movie reviews, genres, directors, runtime, and audience scores from the Rotten Tomatoes dataset.

---

## Features
- Data preprocessing and cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Genre and audience score analysis
- WordCloud visualization
- TF-IDF vectorization
- Cosine similarity recommendation system
- Interactive movie recommendation interface

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- WordCloud

---

## Dataset
Datasets used:
- Rotten Tomatoes Movies Dataset
- Rotten Tomatoes Movie Reviews Dataset

CSV files included:
- `rotten_tomatoes_movies.csv`
- `rotten_tomatoes_movie_reviews.csv`

## Conclusion
This project successfully builds a content-based movie recommendation system using Rotten Tomatoes movie reviews and metadata. TF-IDF vectorization and cosine similarity are used to recommend similar movies based on textual and numerical features.
